# Installer Chrono Sprint (usage personnel)

**Site officiel de l'application :**
https://gabriellecardonnel453-spec.github.io/Chrono-sprint-/

## iPhone 11 (sans App Store)
1. Ouvrir ce lien dans **Safari**.
2. Toucher **Partager**.
3. Choisir **Sur l'écran d'accueil**.
4. Activer **Ouvrir comme app web** si proposé, puis **Ajouter**.

Une icône Chrono Sprint apparaît. Ce n'est pas un fichier IPA natif : une application iOS native distribuée hors App Store nécessite une signature et un provisionnement Apple.

## Xiaomi / Android
**Installation directe sans fichier :**
1. Ouvrir le lien dans **Chrome**.
2. Menu **⋮** > **Installer l'application** ou **Ajouter à l'écran d'accueil**.
3. Confirmer, puis ouvrir Chrono Sprint depuis l'écran d'accueil.

**APK facultatif :**
1. Ouvrir l'onglet [Actions](https://github.com/gabriellecardonnel453-spec/Chrono-sprint-/actions/workflows/android-apk.yml).
2. Sélectionner la dernière compilation Android **réussie**.
3. Télécharger l'archive **Chrono-Sprint-Android-APK** et en extraire le fichier `app-debug.apk`.
4. Sur Android, ouvrir le fichier APK, autoriser ponctuellement l'installation depuis cette source si nécessaire, puis installer.

L'APK est une enveloppe légère autour du site officiel. L'application a besoin d'une connexion pour le premier chargement ; les mises à jour du contenu proviennent du site. Une compilation de test peut être signée différemment d'une compilation future, auquel cas une désinstallation pourrait être nécessaire avant réinstallation. **Éviter l'APK si l'installation Chrome suffit.**

## Confidentialité et mesures
- Aucune publication sur les boutiques d'applications n'est nécessaire.
- Les réglages et l'historique sont stockés dans le navigateur ou l'application sur chaque téléphone ; ils ne sont pas synchronisés.
- **Attention :** le site GitHub Pages et le dépôt actuel sont **publics**, donc l'adresse n'est pas accessible seulement à deux personnes. Usage privé et accès privé sont deux choses différentes.
- Pour le sprint, le GPS du téléphone reste une estimation ; utiliser une piste balisée et une arrivée manuelle ou des cellules pour les mesures rigoureuses.
